# SOCAMM 記憶體檢測組裝機（`DRAM-Inspection`）

載台 PCB 上依序植入 interposer 與 SOCAMM：Tray 供料、三孔取放、PIN 與外觀 AOI、IPA 清潔複檢、視覺對位、三螺絲分段鎖附（評估展示）。

本檔是這個子專案的規則；全庫共通的規則在根目錄 `AGENTS.md`，從這個資料夾啟動 Claude Code 或 Codex 時會一併載入。**實作本站一律照 [`core/SITE-RULES.md`](../../core/SITE-RULES.md)**（開工步驟、實作規則、完成定義、評估簡報）。

## 範圍

- 本站範圍是 `project-site/DRAM-Inspection/`；PR 分支名稱用 `dram-inspection/<說明>`。規則見根目錄 `AGENTS.md`「範圍」。

## 規格摘要

- **資料來源**：`docs/自動化設備-需求清單-開會用.docx`（2026-11-26 初步需求，抽出文字在 `docs/*.extract/text.md`）與 3 張照片（SOCAMM 模組、interposer 連接件正面與 PIN 特寫），只留本機。正式圖面、尺寸、節拍目標都還沒有，數字一律是示意。
- **產品（示意尺寸）**：SOCAMM 90 × 14 mm、三孔（兩端＋偏中間一孔）；interposer 同外形、上下兩面彈片 PIN、底面三處凸點對入 PCB 孔；主機板 300 × 240 mm、**每片 4 組槽位**（槽距 70 mm）；M2 螺絲每組 3 顆鎖入 PCB 背面 PEM 螺帽。模型在 `web/js/parts.js`。
- **組裝順序**：PCB → interposer → SOCAMM，各自確認入位後才鎖固；載台沿 SMT 邊皮帶輸送（輸送面 900 mm）進出，組裝位以頂升＋對角定位銷定位、上推靠壓邊（不從側邊推）。
- **流程**（`web/js/project.js`）：S1 載台進站定位 → S2 Tray 抽屜經上面檢查橋（interposer 頂面 3D 線雷射＋鍍金接點 2D；SOCAMM 正面 2D）→ S3 SCARA 取 interposer（A 頭三孔漲緊）→ 底面 3D 線雷射飛越掃描（PIN 尖端高度／歪斜、平整度）→ 上視相機覆拍修正 → 第一片前下視相機讀 PCB 基準點 → 放入槽位 → 雷射位移計三點入位高度；× 4 → S4 取 SOCAMM（B 頭）→ 離子風刀 → 上視相機底面焊墊 → 髒污件 IPA 擦拭（無塵擦拭帶，2 往返）＋吹乾槽 10 s＋複檢，仍髒送 NG 盒 → 輕放在 interposer 上；× 4 → S5 鎖附模組（該槽 SOCAMM 放好就可開始，但作業期間手臂不得在相鄰槽位；依手臂作業時段排程，必要時先退回待機位讓手臂放隔壁槽）：4 爪壓持（防 PIN 回彈脫孔）→ 3 支雷射量板間距離 → 隨行取釘、三顆預鎖（中間孔先，600 rpm 到貼合）→ 三顆終鎖（60 rpm 到 0.20 N·m）→ 放開、複檢 → S6 出站，原軌道交接。
- **主要選型**：SCARA DENSO HSR065＋RC8A（P-00205，底座轉 180°、雙三孔頭以氣動滑台切換）；邊皮帶輸送（P-00164）、頂升定位與止擋（P-00112）；Tray 抽屜與鎖附 X 軸電動滑台（P-00051）；底面 3D 線雷射（P-00047）、頂面大視野 3D 線雷射（新元件）；Tray 上面 2D 相機（P-00035）、上視相機 × 2（P-00101）、條形光（P-00270）；離子風嘴（P-00219）；伺服電動起子（新元件，扭力／角度／轉數紀錄）；氣動滑台（P-00210）；三色燈（P-00084）、HMI（P-00221）；FFU（一萬級）。
- **配置**：機台 1520 × 1460 mm（不含輸送伸出段），SCARA 在輸送線前方（Z +400），作業點都在半徑 ≥ 330 mm（J2 ≤ 120°，避開基座柱干涉區）；interposer 道在西、SOCAMM 道在東；鎖附模組在輸送線後方，待機位在西端（X −420）。
- **節拍（示意）**：全部良品時每片載台約 101 s（4 組，約 25 s／組；`?scenario=ok`），瓶頸是單支起子的鎖附（每槽約 11.0 s）；含一片髒污清潔約 114 s（清潔期間鎖附模組先鎖已放好的槽位）。手臂作業點、J2 摺角、鎖附與手臂不同時進入相鄰槽位都在 `layoutChecks` 與 `tools/verify.mjs` 檢查。
- **Tray 自動換盤**（`machine.js` 的 `buildTrayLane`）：每道前端是 3 層伺服升降料倉，抽屜叉板（支柱在 Tray 後方 160 mm）伸入層架之間；使用中的 Tray 取完就送回空層、料倉上升托離、叉板退出、料倉下降一層、叉板伸入滿盤下方、料倉下降把滿盤放上叉板，再經檢查橋送到取料位。Tray 6 格（4 片＋備品），空盤留在料倉下層等人員取出。
- **電控（第二段，`web/js/electrical.js`）**：下方機櫃中空，西側前方是電控盤（背板 3 列：電源保護與 PLC、I/O；PoE 交換器、視覺工控機、光源控制器、起子控制器、MES 閘道；伺服驅動 × 7），東側前方是 RC8A（層板），東側背板是 FRL＋8 連閥島（P-00119）。台面 6 個走線孔：鎖附拖鏈、Tray I 拖鏈、上視相機 I／S、手臂底座出線、頂升氣管；外露線路照 core 第二段寫法，`electrical` 檢查與配線動態取樣都通過。視角「電盤配線」打開櫃門。
- **情境**（網頁「情境」或 `?scenario=`）：`clean`（預設，SOCAMM #2 髒污 → 清潔後 OK）、`ok`、`ng-clean`（清潔後仍髒 → NG 盒、改取備品）、`ng-pin`（interposer #3 底面 PIN 歪斜 → NG 盒）。
