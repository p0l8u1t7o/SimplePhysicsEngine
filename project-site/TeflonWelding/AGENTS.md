# 鐵氟龍襯裡桶自動焊接（`TeflonWelding`）

1000L 襯 PTFE 桶內焊道：DENSO 手臂熱風焊接＋兆赫波檢測（A 臥式迴轉採用，A2 雙工位評估；B、C 為參考）

## 規格摘要

- 2026-11-11 客戶會議（依 `docs/20261111_鐵氟龍襯裡桶自動焊接評估.pptx` 討論）的 7 項反饋已改進動畫與簡報（`docs/20261116_鐵氟龍襯裡桶自動焊接評估_客戶反饋修訂.pptx`）。
- 資料來源（2026-11-03）：`docs/1000L.step`（主力 1000L 桶）、切半展示品照片與焊道標記、`Sample for Detection.pdf`（膠體斷面：SUS／膠／PTFE，開 V 槽 → 焊條熔接 → 削平 → 焊帶熔接）、`LHS SYSTEM 21S.stp`（手臂前端熱風焊槍）、對談紀錄（焊槍前方另有約 80 mm 拖嘴）。
- 桶（STEP 量得，`web/js/spec.js`）：SUS304 內徑 1000、壁厚 4、直筒 1290、碟形封頭（球面 R1004、轉角 R96.8）；頂部人孔頸內徑 459（襯 PTFE 後約 453）、法蘭外徑 705；底部出口 Ø165。PTFE 3 mm＋膠 1 mm、四支外撇管腳都是假設。
- 焊道（照片判讀，位置為假設；網頁側欄可調，網址 `?c1=&c2=&nl=`，環縫 250～1000（C 案 875）、兩環縫至少相距 250、縱縫 1 或 2 條）：預設兩道環縫（離下切線 420、870）＋中段一道縱縫；整桶的標記處全部要焊，焊道總長約 6.7 m。
- 製程（6 道，照膠體斷面圖的順序）：相機定位（3D 相機沿焊道取像 → 軌跡規劃）→ 開 V 槽（CNC 電主軸＋90° V 形銑刀＋靠模控深，雷射循縫；全罩毛刷吸屑，每道焊道開完回程吸屑一趟）→ 焊條熔接（熱風 250 °C 設定值待確認，Leister LHS 21S＋拖嘴；熱風吹軟後定力下壓 5 kgf，拖嘴後方 UV 405 nm 線雷射即時量焊道寬度與高度；NG 時導管出口氣動切刀切斷焊條）→ 削平（刮平，斷面圖的 Flat cut）→ 焊帶熔接（同型焊槍＋壓輪）→ 兆赫波（THz）檢測（桶內要裝氫氟酸）→ NG 補修與複檢。規格在 `spec.js` 的 `CNC`、`ROD_WELD`。
- NG（`spec.js` 的 `NG_HANDLING`，網頁與簡報都有表）：每道工序都是「偵測 → 該線停止、安全退出 → 紅燈＋HMI＋推播 → 人員接手 → 復歸續做」。動畫演示兩種：下環縫焊條熔接到 30% 處 UV 判 NG → 切斷焊條、退出、人員刨除 30 mm → 復歸後從刨除處續焊（`ROD_NG`）；上環縫一處氣孔 THz 判 NG → 通知人員人工補修（刨除 → 補焊條 → 削平 → 焊帶，缺陷前後各 60 mm）→ 自動 THz 複檢 OK。人員是示意模型（`operator`，不採購）。
- 手臂一律 J1 與桶軸同軸、伸直穿過人孔，進桶後展開；6 支工具（3D 相機、CNC 刀頭＋雷射循縫、焊條焊槍（下壓＋UV 線雷射）、削平刀、焊帶焊槍、兆赫波探頭）經快換盤自動更換，工具長度統一 300 mm（同一組焊接姿態適用全部工具）。
- 桶內即時影像（2026-11-16 客戶補充）：手腕相機一台（`tools.js` 的 `createAtc`，裝在手臂側快換盤旁的 −Y／+X 象限、斜看作業點，不隨工具更換），6 道工序都看得到；網頁相機視窗預設就是這台相機的視角（`main.js` 的 `liveCam`），兆赫波檢測期間左側即時影像、右側 A-scan／B-scan 並列；原本的焊點特寫改成「觀察視角（示意）」來源。
- 檢測方案比較（`spec.js` 的 `INSPECTION`）：THz 保留做內部檢測；2D 視覺（外觀）、雷射輪廓（尺寸，含工序 4 UV 線雷射）、火花測試（出貨）並列比較，建議組合使用。
- 四個方案（網址 `?plan=`；A 採用、A2 評估、B／C 參考）：
  - `roll` A 臥式迴轉＋伸臂：開合式雙環迴轉架、懸吊 X 軸伸臂、VS-068 裝在伸臂前端；桶轉焊環縫、伸臂走縱縫，全部平焊。
  - `dual` A2 並排雙工位＋雙臂：兩套 A 案迴轉架與 X 軸伸臂並排（兩線中心 z＝∓1000），各一台 VS-068；一組 6 支工具放在 Z 向穿梭工具架上兩線共用。排程用資源互鎖（每支工具、工具架一次只給一線，時間最早的一線先推進，等待標在事件列）。第 2 線接手點 `?handoff=all|rod|belt`（預設 rod：人員已做完開 V 槽）。實際工時估算 `dualEstimate`：全自動約 1.4 h／桶、從焊帶接手約 1.1 h／桶（單臂 2.6 h）。
  - `turntable` B 立式轉台＋升降柱：轉台定位四支腳，立柱懸臂（上下＋伸縮）帶 VS-068 倒吊進桶；轉台轉焊環縫、懸臂升降走縱縫（橫焊／立焊）。
  - `cobot` C 移動門架＋協作臂：桶不動，門架推到桶上方，COBOTTA PRO 900 倒吊進桶；J1 繞 360° 焊環縫、Z 軸走縱縫。
- 工時（`spec.js` 的 `PROCESS.speed`，假設）：焊條、焊帶 0.15 m/min，開槽、削平 1 m/min（開槽另加回程吸屑 3 m/min），檢測 0.6 m/min，約 2.6 小時／桶（`cycleEstimate`，`review/verification.json` 的 `estimate`）。動畫為示意時間：每道焊道固定幾秒播完（`DEMO`），焊接段比實機壓縮約 250 倍。
- 兆赫波原理與判定（`spec.js` 的 `THZ`、`web/js/thz-view.js`）：反射式時域，每個介面一個回波，Δt 換算厚度；PFA 與 PTFE 折射率幾乎相同，熔合良好時交界幾乎無回波，氣孔（空氣層）多一道相位反轉強回波。判定：多餘回波 > 表面回波 15% 為 NG、覆蓋厚度 ≥ 3.2 mm、交界回波 < 8%（數值為示意）。相機視窗在檢測與補焊複檢期間自動切到波形畫面（A-scan、B-scan、各焊道判定）。
- 檢查：`tools/verify.mjs` 四案各跑一次——TCP 跟隨焊道（≤ 2 mm，含續焊與回程吸屑）、手臂／載具／工具逐頂點對每一線桶壁的間隙、製程順序與完成、人員補修時手臂不在桶內、A2 的工具與工具架互鎖；極端焊道排版由完整檢查的 `tools/verify-extreme.mjs` 再跑一次；人孔通過與 IK 收斂在 `layoutChecks`。
