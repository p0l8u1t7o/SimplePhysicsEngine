# 杯體加工件 AOI 與共焦量測（`WorkpieceMeasurement`）

鋁質殼體 AOI 取像與上下共焦量測的半自動量測機。

本檔是這個子專案的規則；全庫共通的規則在根目錄 `AGENTS.md`，從這個資料夾啟動 Claude Code 或 Codex 時會一併載入。

## 範圍

- 本站範圍是 `project-site/WorkpieceMeasurement/`；PR 分支名稱用 `workpiecemeasurement/<說明>`。規則見根目錄 `AGENTS.md`「範圍」。
- core 缺功能：先在本站暫代，並登記到 `core/REQUESTS.md`。
- 待辦與待確認事項記在根目錄 `PENDING.md`「各站待確認」。

## 規格摘要

- 資料來源（`docs/`，只留本機）：AOI 光學檢測規格書（.docx，Rev. A）、零件圖面影像（.jpg，其中三張是杯體 A／B／C）、共焦感測器報價單（.pdf）與報價核對、電控與整線規劃文件、成本試算（匯入平台前的原檔，成本以 3D工作室平台的 BOM 為準）。尺寸、門檻與機構配置都在 `web/js/spec.js`。
- 工件：三種杯體加工件（機構零件），規格 A 4.2 短杯（外徑 Ø4.805）、B 9.91 中杯（Ø4.76、壁厚 0.18）、C 13.8 長管（Ø4.85、口部 Ø4.3 縮頸）；底厚判定 A 0.221～0.297、B 0.16～0.20、C 0.80～0.95 mm。
- 架構：半自動，人工擺托盤，機內移載自動取放與量測；花崗岩平台＋避震（P-00195），台面高 900 mm。
- 流程：S0 取料（入料托盤對列、側向真空吸嘴貼靠外壁）→ S1 ST1 三爪夾持、三個光學通道共用一次裝夾 → S2 移載到 ST2 落座薄環座 → S3 ST2 上下共焦螺旋掃描（5 圈、120 rpm）差分求底厚 → S4 判定分料（OK／NG1／NG2，ERR 重測一次後退回原穴）。
- ST1 光學：通道 A 線掃相機 Basler raL4096-24gc 或同級（P-00176）＋線掃遠心 1.5×（P-00177）＋RGB 三角度線光源（P-00178，紅光暗場／綠光明場），θ 轉 1 圈展開；通道 B IDS 5MP＋0.5× 雙遠心（P-00179）＋遠心平行背光（P-00180），0／90／180／270° 剪影量外徑；通道 C IDS 5MP＋1× 遠心（P-00181），在 DD 馬達上方經中空軸看杯口端面。
- ST1 夾持：DD 中空軸馬達（P-00182）＋三爪 PEEK 夾頭（P-00183），夾持力 1.5 N（規格 B 上限 2 N）。
- ST2 測厚：Keyence 共焦套組 CL-3000＋CL-S015 ×2＋CL-S015N ×2＋CL-CV5 ×2＋OP-88864（P-00184）上下對置；空心軸 θ 平台（P-00187）、R 軸微動台承載整個 C 型架（P-00188）、上頭避讓 Z 軸（P-00185）、可換式鎢鋼環座 ×4（P-00189）。
- 移載：X 軸約 520 mm 行程（P-00190，≤ 1200 mm/s）＋Z 軸電動滑台（P-00191，≤ 400 mm/s）＋6 mm 貼靠氣缸與側向真空吸嘴（P-00192）；托盤梭台 ×2（P-00193）、導電托盤（P-00194）：入料 5×4、OK 5×4、NG1 2×4、NG2 2×4，穴距 12 mm。
- 控制：Keyence PLC 與 EtherCAT 主站（P-00196）、安全控制器與門鎖（P-00197）、視覺工控機（P-00198）、HMI 與燈號（P-00199）；校正件：標準厚度片（P-00200）、標準環規與標定板（P-00201）。
- 節拍：規劃約 11.4～11.6 s／件（約 310～316 UPH）；ERR 重測一次約 16.6～16.7 s。規格書是 9.4 s，模擬因進 ST2 前要多一個升降點而較長。
- 選配與備案（BOM 數量 0）：內壁檢測 P-00202、自動上下料 P-00203、規格 C 接觸式深度計 P-00204、替代光學方案 P-00186。
- 假設與待確認：量測值、缺陷、有效點數都是 `spec.js` 的示意值；外觀允收基準、底部平整度、夾持力與夾持變形沒有實測依據（規格書 R-04、R-05）；CL-S015 杯口光路待原廠光路圖與實物驗證；吸嘴貼靠帶（規格 A 只剩 1.7 mm）要實物確認；設備外廓是工程規劃包絡，不是原廠 CAD。
- 完整說明見 [README.md](README.md)。

## 已拍板事項

- 照規格書做半自動；只做殼體 A／B／C。
- 與規格書不同的地方已列在 README。規格 A 底孔、規格 C 口部依圖面判讀。
- 整機架構照規格書半自動，不改 SCARA 全自動或分度盤。
- 工件只做三種杯體加工件 A／B／C，`docs/` 內的沖壓板件與帶齒管件不納入。
- 判定情境做 OK、NG-D、NG-A、NG-T、ERR 五種；NG 件仍走完全部量測，ERR 不當成 NG。
- 配套做取像模擬相機視窗、驗證腳本與成本估算表。
- 移載、Z 滑台、貼靠氣缸、R 軸微動台、DD 馬達、θ 平台、共焦感測頭不換用 core 模型，幾何維持 `spec.js` 的純資料（畫面與干涉檢查同源）。
- 工件稱為「杯體加工件」、用途是機構零件；舊規劃書的工件命名不採用（使用者確認）。
