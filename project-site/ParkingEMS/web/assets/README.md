# ParkingEMS 渲染素材

素材隨本站封裝，載入時只連本站來源，不依賴第三方服務。`manifest.json` 記錄原始 URL、授權及 SHA-256。取用日期：2026-10-14。

`.gitattributes` 固定 vendor 文字檔為 LF、紋理為二進位，避免跨平台 checkout 改變雜湊。單檔 HTML 的授權全文由本站 `index.html` 一併保留。
