# 停車場光儲充能源服務（`ParkingEMS`）

三種場型（旗艦型光儲充、住商型與都會型市電儲能充電）的建置流程、全天 EMS 調度與停充整合

本檔是這個子專案的規則；全庫共通的規則在根目錄 `AGENTS.md`，從這個資料夾啟動 Claude Code 或 Codex 時會一併載入。

## 範圍

- 本站範圍是 `project-site/ParkingEMS/`；PR 分支名稱用 `parkingems/<說明>`。規則見根目錄 `AGENTS.md`「範圍」。
- core 缺功能：先在本站暫代，並登記到 `core/REQUESTS.md`。
- 待辦與待確認事項記在根目錄 `PENDING.md`「各站待確認」。

## 規格摘要

資料來源（`docs/`，只留本機）：停車場能源服務提案簡報（PDF／PPTX，27 頁）、舊版 72 秒概念動畫、三種場型比較表截圖。合作對象名稱不得出現在本站任何檔案（已在本機名單）。配置與容量都在 `web/js/sites.js`，標「假設」的要依現勘、12 個月帳單與報價重算。

```
?site=flagship｜mixed｜urban（三種場型，各一條時間軸）
現況 → 建置（分區圍設、吊車吊裝）→ 系統聯測 → 全天 EMS 調度（24 h 壓成 36 s）→ 客戶停車充電；都會型另有模組擴充
```

| 項目 | 旗艦型 | 住商型 | 都會型 |
|---|---|---|---|
| 車位分級（提案） | 100 以上（動畫 148 格） | 50–99（72 格） | 20–49（28 格） |
| 場地（照片辨識） | 開闊露天 | 住商周邊平面 | 狹長入口、車道受限 |
| 光電 | T 型車棚 192 片 × 520 Wp ≈ 100 kWp | 不建置 | 不建置 |
| 儲能（假設） | 100 kW／215 kWh | 50 kW／100 kWh | 30 kW／64 kWh，擴充再加一組 |
| 充電（假設） | AC 7 kW × 8（掛車棚立柱）＋ DC 60 kW × 2（充電島） | AC 7 kW × 10（北排夜泊）＋ DC 預留 | DC 40 kW × 2＋AC 7 kW × 2（擴充 +DC × 1） |
| 契約容量（假設） | 150 kW（高壓受電＋變壓器） | 60 kW | 45 kW（擴充時檢討為 75 kW） |
| 憑證 | 合格光電可評估 | 市電儲能不產生 | 市電儲能不產生 |

- **調度規則**（`web/js/energy.js`，提案第 10、11 頁）：15 分鐘一步，連續模擬 4 天取穩態；離峰先給夜泊直充、剩餘補儲能到目標 SOC（旗艦型只補到 35%，白天留給光電）；光電優先供負載、剩餘充儲能再輸出；半尖峰／尖峰削峰；超過契約容量時先多放電、再少充、最後依公告規則限 EV 功率。往返效率 90%。時段（離峰 22–9、半尖峰 9–16、尖峰 16–22）與費率是示意。
- **客戶情境**：旗艦型 14:00 DC 快充（光電＋儲能）；住商型 19:00 住戶進場、排程 22:00 離峰直充、隔日 07:30 離場；都會型 17:35 尖峰快充，18:00 後 SOC 偏低遇到動態限功率。插槍要顯示價格確認與啟動成功，帳單停車＋充電合併結算。
- **入口**：閘門設在場內（旗艦、住商在交叉車道、都會在狹長車道離街 6.5 m），等候車輛不占用街道。

## 假設與待確認
