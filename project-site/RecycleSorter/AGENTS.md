# 回收物自動分揀展示機（`RecycleSorter`）

架在現場既有 ABB 並聯手臂分選站後段的補抓站：兩站共用雙相機立體視覺，ABB 來不及抓的白色 HDPE 由 DENSO HSR065 SCARA 補抓到兩條分流帶；同類連抓 1.4 s／瓶、混合料流約 1.5 s。

本檔是這個子專案的規則；全庫共通的規則在根目錄 `AGENTS.md`，從這個資料夾啟動 Claude Code 或 Codex 時會一併載入。

## 範圍

- 本站範圍是 `project-site/RecycleSorter/`；PR 分支名稱用 `recyclesorter/<說明>`。規則見根目錄 `AGENTS.md`「範圍」。
- core 缺功能：先在本站暫代，並登記到 `core/REQUESTS.md`。
- 待辦與待確認事項記在根目錄 `PENDING.md`「各站待確認」。

由 3D 動畫生成應用程式（vs3d）以 Claude opus 規劃與開發、Codex gpt-6 渲染補強產生，2026-10-04 匯入本庫。說明見 [README.md](README.md)；配置提案在 `docs/proposal.md`（只留本機）。

### 2026-10-05 補上前段（既有 ABB 分選站）

使用者的指示（摘錄，錯字已更正）：

> 請閱讀 docs/20261002-現場拍攝照片影片 內的資料，目前現場已經有一套自動化分選系統，使用 ABB 手臂和視覺系統，但因為辨識能力不佳，所以需要開發另一套視覺辨認系統取代，
> 目前網頁 3D 流程的方案是要架在 ABB 手臂的後段，用來補強 ABB 手臂撿漏的 HDPE。
>
> 請在 3D 動畫中補上 ABB 手臂的位置和之後使用新視覺系統整合的系統流程，ABB 手臂的視覺系統和 DENSO 的視覺系統一樣，都採用雙視覺高度檢測。

現場資料（`docs/20261002-現場拍攝照片影片/`，只留本機）：29 張照片與一段 41 秒的影片。判讀到的重點：

- 手臂是 ABB IRB 360 FlexPicker（並聯手臂，工作直徑 1600），吊在藍色鋼構網籠頂部；控制器 OmniCore C30，另有輸送帶追蹤模組（接編碼器與相機觸發）。
- 工具是吸塵器式真空吸嘴，側接大口徑軟管；吸塵器放在電控櫃下層。人機畫面有吸取次數、四個落料區、輸送帶速度與安全門／急停狀態。
- 輸送帶是綠色平皮帶、鏽色鋼板側牆；料流由上游料斗進來，經 ABB 網籠，下游有人工揀選，皮帶末端落料。
- 現場照片與人機畫面上有既有系統廠商的名稱，**不得寫進本站任何檔案**（設備廠牌 ABB、DENSO 不在此限）。

這一輪沒有逐項問使用者，以下是依現場資料採用的做法，**都還沒拍板**（待確認事項記在根目錄 `PENDING.md`）：

- 前段的位置與尺寸全部是照片目測的示意值；ABB 抓取線在後段取像站上游 2100 mm。
- 既有輸送帶與後段主帶同高同寬，中間用過渡板銜接。
- 前段立體取像站與後段同相機、同鏡頭、基線 300，工作距離加高到 1050，雙眼重疊視野才蓋得住 600 帶寬。
- ABB 單趟 1.15 s、抓取窗口 ±50 mm，規則是先到先抓、沒空就放行；放行的目標由後段補抓。
- ABB 的落料：食品 HDPE 落 −Z 側滑槽、非食品落 +Z 側，各兩個收料籃（對應人機畫面的四個落料區）。
- 動畫總長由 96 s 改為 117 s；後段的工單、節拍與相對時序不變。
