# 第一次渲染與細節補強

本輪僅補強外觀。96 秒時間軸、工件料流、取放事件、原有 `apply(t)` 狀態與動件名稱不變；`layoutChecks()` 的 22 筆結果（含數值）與補強前一致。

| 審查項目 | 完成內容 |
|---|---|
| S1、S2 | 看板改為 290 × 90 mm，掛在橫樑後側、朝 −Z；兩行使用相同字級，縮短規格文字，保留「示意」。 |
| S3、S4 | 概觀鏡頭提高並向 −X 調整；出料鏡頭移至 +Z 上方，注視兩條帶中點。地面加入 A／B 相反方向箭頭。 |
| S5 | 食品包裝藍綠／白、非食品包裝橘紅／白；圓瓶用瓶身 UV 環繞貼圖，扁瓶補頂面標籤，並加條碼與掉墨。圖樣為示意。 |
| S6 | 主帶改為深綠霧面，分流帶為深灰霧面；以低對比刮痕、水漬及細接縫取代高對比條紋，原 UV 移動速率不變。 |
| S7 | 工站標籤錯開位置與高度；尺寸標籤移到設備側面；所有畫面啟用框架內建的標籤避讓。 |
| S8 | 取像橫樑增加頂部雙斜撐、固定片、側溝槽與端蓋，維持原有架台外廓。 |
| S9 | 取像區增加漸淡橢圓亮斑，隨既有 running 條件開關；沒有額外陰影光源。 |
| S10 | 鋁擠型、烤漆灰鈑金／電控箱、拉絲支撐板採用不同明度與粗糙度。 |
| S11 | 導料板加上緣折邊、入口圓角包邊、長孔調整片、蝶形旋鈕與開口標示，600 → 280 開口不變。 |
| S12 | 防汙視窗加密封膠條、倒角外框、清漆反射與小標；避免折射背景的額外重繪。 |
| S13 | 鏡頭增加環狀溝槽、壓板螺絲、機背網路及電源接頭凸座，沒有新增配線。 |
| S14 | ±X 兩端補上半部護板框，保留輸送帶穿越口；側邊立座加四面三角肋板、底板墊片與螺栓。 |
| S15 | 修正 850 mm 註解；UI 顯示 7 連抓；說明模型庫 12 款、動畫 11 款；收料箱增加翻邊及底部叉孔外觀。 |

新增洗衣精工件會改變事件與統計，違反本輪硬性限制，因此未排入。滿載段原 note 是 `apply(t)` 的既有狀態欄位，保留原值並在 UI 修正顯示文字。包裝、結構細節與叉孔尺寸均屬外觀示意，未進行製造或負載驗算。

驗證命令（專案目錄）：

```powershell
node --import ../../core/tools/register.mjs tools/render-audit.mjs
node ../../core/tools/check.mjs RecycleSorter --quick
```

`render-baseline.json` 保存補強前基準；`render-audit.json` 保存本輪比較。961 個時間點的狀態、工件與手臂矩陣摘要一致。新增 InstancedMesh 另展開成同幾何與同矩陣的 Mesh 做干涉／重合面檢查，以補足 core 一般檢查略過實例網格的部分。

最大可見三角面數 23,456 → 26,868（+14.55%）；材質群組繪製批次上限估算 357 → 389（+8.96%）。此為無瀏覽器估算，不是 GPU 實測。介面截圖、實際 draw call 與手機幀率依規則交由 app 後續檢查。
