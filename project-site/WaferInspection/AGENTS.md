# 晶圓表面 AOI 檢測評估（`WaferInspection`）

單片晶圓＋XYθ 平台＋固定上視相機，同軸明場／低角度暗場掃描檢測的方案評估（參數為展示假設）

本檔是這個子專案的規則；全庫共通的規則在根目錄 `AGENTS.md`，從這個資料夾啟動 Claude Code 或 Codex 時會一併載入。**實作本站一律照 [`core/SITE-RULES.md`](../../core/SITE-RULES.md)**（開工步驟、實作規則、完成定義、評估簡報）。

## 規格摘要

- 資料來源（`docs/`，只留本機）：客戶提供的晶圓表面照片 6 張（1936×1096 PNG）與 3 張含人工紅色箭頭的截圖；應用背景是 AI 伺服器。產品類型、晶圓與 die 尺寸、缺陷規格、節拍、允收規格都未提供。
- 照片觀察：重複圖案、線陣、點陣、大面積區塊；照明呈水平帶狀，上方約 1/4 很暗（分帶亮度最多差 7～10 倍）；004 可見晶圓邊緣與吸盤；005 疑似經過影像處理（色階斷層）；照片之間倍率、方向、位置都不同，不能拼接。
- 疑似異常：截圖中客戶以紅色箭頭標出的疑似暗線（人工標記），只稱「疑似線狀表面異常」，不判定為裂紋。
- 第一版配置：單片晶圓＋真空吸盤＋XYθ 平台＋固定上視面掃相機＋同軸明場／低角度暗場切換（評估用，不是客戶規格）。人工放片後開始，不含搬運與剔除，缺陷以 wafer map 與複檢清單記錄。
- 流程：真空確認 → 兩點對位與 θ 修正 → 5 點對焦平面 → 停拍掃描（每位置明場＋暗場各 1 張）→ 複檢 → 結果輸出。
- 選型：相機沿用 P-00035（20MP、2.4 µm、GigE）；1× 同軸遠心鏡頭、同軸光、低角度環形光、XY 平台、θ 台、Z 調焦軸、真空吸盤為新元件（示意，待詢價）；P-00039、P-00195、P-00196、P-00197、P-00198、P-00199、P-00072 沿用。
- 展示假設：300 mm 晶圓、邊緣排除 3 mm、die 10×10 mm、目標缺陷 10 µm、重疊 10%、停穩 0.08 s、明場 0.5 ms、暗場 5 ms（全部在 `web/js/spec.js`，畫面標來源）。
- 估算：視野 13.29×8.86 mm、2.4 µm/px、缺陷 4.2 px、景深約 0.154 mm；777 個位置、1554 張、約 31.8 GB；整片約 300 s（GigE 傳輸是瓶頸），10GigE 約 176 s；線掃描 16k 約 39 s（僅參數比較）。倍率 2× 時景深約 58 µm 小於平面度假設，約 1092 個位置待複檢、週期約 1730 s（GigE），提高倍率要搭配即時自動對焦。
- 模擬情境：無注入缺陷、線狀表面異常、顆粒／污染、失焦或照明不足（待複檢）；缺陷真值、演算法候選、人工待確認三類資料分開。
- 限制：晶圓薄膜干涉、細密圖案繞射、真實缺陷散射無法由近似光學模型預測，示意影像不能代替打光 POC；像素數足夠只代表幾何取樣條件。
- 程式：`web/js/spec.js`（參數與來源）、`budget.js`（core/optics 光學＋週期）、`scan-plan.js`（掃描位置與覆蓋）、`inspection-sim.js`（示意圖樣、相機模擬、演算法、複檢）、`sequence.js`（時序）、`wafer.js`、`machine.js`、`views2d.js`、`main.js`；自有檢查 `tools/verify.mjs`。
- 評估資料在 `.studio/plan/`（只留本機），成本表在平台 `@WaferInspection`；新元件 P-00242～P-00254 都是待詢價，成本表目前只含已知項。評估簡報用 `tools/assessment-extra.mjs <shots 截圖資料夾> [情境截圖資料夾]` 產生（先跑 `vs3d assess deck`，再補光學、節拍、演算方式與界線頁）。

## 已拍板事項

- 主標題用中性的「晶圓表面 AOI 檢測評估」；AI 伺服器只是客戶提供的應用背景，不把產品命名為特定 GPU、HBM、CoWoS 或任何廠商型號。
- 疑似暗線不定義為裂紋；不宣稱光學照片能判定晶體管、奈米線路或內部電性缺陷；畫面區分「客戶參考照片」「示意模型」「幾何估算」「待實測」。
- 第一版主方案：單片晶圓＋真空吸盤＋XYθ 平台＋固定上視面掃相機＋同軸明場／低角度暗場切換（評估用配置，不是客戶規格）。
- 從「人工手動放妥晶圓」開始，展示真空確認後的對位與檢測；不做 FOUP、搬運手臂、自動拆盒與分選，缺陷只記錄在 wafer map，不演實體剔除。
- 300 mm 晶圓與其他展示參數一律醒目標為假設；缺值顯示「待確認」，不當成 0。
- 四種固定情境（無注入缺陷、線狀表面異常、顆粒／污染、失焦或照明不足＝待複檢）；A 模擬真值、B 演算法候選、C 人工註記／待確認分開；所有結果標 SIM，不顯示信心分數。
- 線掃描只做參數比較，第一版不建第二套線掃設備動畫。
