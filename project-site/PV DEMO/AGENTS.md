# 屋頂光伏電場（`PV DEMO`）

鋸齒屋面與鋼架斜置陣列的屋頂型光伏電場：一天的日照、發電與併網

本檔是這個子專案的規則；全庫共通的規則在根目錄 `AGENTS.md`，從這個資料夾啟動 Claude Code 或 Codex 時會一併載入。

## 規格摘要

資料來源：`docs/` 裡的一張屋頂實景照片（只留本機）。目前是**初步動畫**，尺寸與選型都是依照片推估的假設值，集中在 `web/js/layout.js`。

- 建物：60 × 36 m、屋面高 12 m、女兒牆 1.1 m；東北角塔樓（樓梯間＋機房，高 6.5 m，西面外掛鋼梯、屋頂天線與碟形天線）。
- 鋸齒屋面陣列：4 排南向斜面（水平 4800、高 2100，傾角約 23.6°），每排鋪上兩排直放板 × 42 片；斜面下緣留空約 1.8 m，冬至正午前排屋脊陰影不落在板面。
- 鋼架斜置陣列：3 排 × 3 座桌台，每座 2 排直放 × 8 片，傾角 20°，排距 4400（冬至正午無遮蔭所需 4288）。
- 模組：250 W 多晶矽（1640 × 992 × 40），共 480 片、120 kWp。
- 變流器：3 台 40 kW 組串式（INV-1：鋸齒第 1、2 排；INV-2：鋸齒第 3、4 排；INV-3：鋼架陣列），在塔樓東側遮陽棚下；交流配電盤 → 沿東外牆下到地面變壓器與電表（市電併網點）。
- 發電模型（`web/js/solar.js`）：春分、北緯 23°、真太陽時；晴空 Meinel 衰減＋固定比例散射；每片板以中心射線判定遮蔭（塔樓、前排、雲影）；直流綜合損失 0.86、變流器效率 0.97、啟動日射量 25 W/m²。
- 動畫：一天（5:36～18:36）壓縮成 61 s，六站：日出併網、上午爬升、正午峰值、雲層遮蔽、午後下降、日落日結。
