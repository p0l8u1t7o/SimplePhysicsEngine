# 3D 設備動畫工作區 — 共通規則

本工作區由 3D 動畫生成應用程式（vs3d）管理，只用在部署版（開發機上的 3D工作室直接在本庫的 `project-site/` 工作，規則是本庫根目錄的 `AGENTS.md`）。你是代理，在 `projects/<專案>/`（你的工作目錄）裡建立或修改一個 3D 設備動畫專案。本檔與 `core/` 都是唯讀的。

**實作規則一律照 `../../core/SITE-RULES.md`（必讀）**：閱讀順序、開工步驟、實作規則、完成定義、評估簡報。API 的寫法在 `../../core/README.md`。本檔只寫 app 管理下的特別規定，兩者衝突時以本檔為準。

## app 管理下的特別規定

- 說明、標籤與程式註解一律用繁體中文（台灣用語）；程式碼、變數、檔名用英文。
- **只改自己的專案資料夾**。`core/`、本檔、其他專案都是唯讀；app 每輪結束都會比對，越界的修改會被還原並記為違規。
- **不要執行** `git commit`／`checkout`／`reset`／`restore`／`stash`／`clean`。版本控制由 app 負責，每輪前後會自動 commit。
- **不要上網、不要安裝套件**。
- **要問使用者時寫問題檔**（格式見下），然後結束這一輪；app 會問使用者，回答後讓你接著做。有合理預設值的小事自己決定，在結束訊息中說明。
- **選型先查元件資料庫清單**：工作區裡沒有元件庫的命令列，改讀專案的 `.studio/parts-catalog.md`（app 每次執行前更新，不要修改）。清單裡的參考單價是預算價，只用在提案與成本估算，不要顯示在網頁上。
- **參考站**：提示裡列了參考站（本庫已完成的站）時，它們是唯讀的範例：讀它們的 `web/js/` 看細節水準與寫法，不要複製場景、不要套用它們的規格與拍板事項、不要修改；它們的 `docs/`、`.studio/`、`TEMP/` 是使用者的本機資料，不要讀。規格摘要由 app 複製在 `.studio/references/`。
- **core 缺功能**：先在專案裡暫代，再把需求寫到 `.studio/core-requests.json`（格式見提示開頭），app 每輪結束後登記給 core 維護者；不要改 `core/`。
- `AGENTS.md`（需求、規格摘要、已拍板事項）由 app 寫入，代理不要改；規格摘要來自規劃角色寫的 `.studio/plan/spec-summary.md`。
- 結束前一定要跑快速檢查並修到通過：`node ../../core/tools/check.mjs "<專案資料夾名稱>" --quick`。app 也會自己跑檢查，以 app 的結果為準。
- **看畫面用 `node ../../core/tools/snap.mjs "<專案資料夾名稱>" --view <視角> --t <秒>`**（`--list` 列出視角；一次最多 8 張，輸出在 `TEMP/snap/`，用讀檔工具打開圖片）。改了外觀、配置或動作就拍來看。**不要跑 `ui-check`／`shots`、不要自己啟動伺服器**，也不要另寫替代的瀏覽器測試工具；snap 在沙箱裡開不了瀏覽器就略過。app 會在你結束後跑完整檢查與截圖，有問題會把結果回送給你；開發完成後 app 會把截圖交給同一個開發代理**自我檢查**（預設 2 次）。
- 結束訊息用幾行條列：做了什麼、做了哪些假設、還有什麼沒做。

## 問題檔

寫到 `.studio/questions/<id>.json`（`id` 用英數與 `-`，同一個問題不要換 id 重問）：

```json
{
  "id": "layout-1",
  "header": "站位配置",
  "question": "完整的問題，結尾用問號？",
  "options": [
    { "label": "選項名稱（1～5 個詞）", "description": "這個選項的意思與影響：節拍、成本、工時、之後的限制" },
    { "label": "另一個選項", "description": "…" }
  ],
  "recommended": 0,
  "multiSelect": false
}
```

- 一輪最多 4 題，每題 2～4 個選項；建議的選項放第一個，`recommended` 填它的索引。使用者也可以不選，改寫自己的說明。
- `header` 最多 12 個字。選項要互斥（`multiSelect` 為 true 時除外）。
- 已經回答過的問題在 `.studio/answers/`，也會寫進專案 `AGENTS.md` 的「已拍板事項」；不要重問。
